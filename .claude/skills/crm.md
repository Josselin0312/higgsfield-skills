# crm

Gestionnaire visuel pour les skills Higgsfield avec tracking des revenus.

Affiche un dashboard avec:
- 📊 Revenus totals et par skill
- 📈 Historique des générations
- 🎨 Skills disponibles (image, video, analysis)
- 💰 Coûts et statistics

## Usage

`/crm dashboard` - Afficher le dashboard principal  
`/crm revenue` - Voir le breakdown des revenus  
`/crm history` - Afficher l'historique des générations  
`/crm init` - Initialiser la base de données

## Examples

```
/crm dashboard
/crm revenue
/crm history
```
