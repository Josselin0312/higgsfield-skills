# CRM Skills Hub

Un dashboard visuel pour gérer les Higgsfield skills avec revenus.

## Commandes disponibles

- `/skills-dashboard` - Voir le dashboard complet
- `/generate-image` - Générer une image
- `/generate-video` - Générer une vidéo
- `/view-revenue` - Voir les revenus
- `/history` - Historique des générations
